# Email signature assets

Images used by Joemark Basa's email signature (hotlinked from raw.githubusercontent.com so they load in every inbox).

- `photo.png`: 216x216, pre-cut circle (shown at 72 px)
- `icon-*.png`: 48x48 contact icons (shown at 16 px). Icon glyphs from [Bootstrap Icons](https://icons.getbootstrap.com/) (MIT).
